(tags wcag2a, wcag2aa, wcag21a, wcag21aa, best-practice) at 412 px and 1440 px, light and dark.
Serious or critical violations fail the run.

The M3 token set already met AA contrast; no token values changed. Open moderate items: heading levels skip on
some screens (h1 app bar to h3 cards) and two `nav` landmarks share a label on wide windows.

Large text: `pnpm ui --widths 412 --themes light --zoom 2` sets the root font size to 200 % (axe is skipped). Fixed
heights were changed to minimums (StatusLabel, chips, buttons, segmented button); the tracker store header and
"Now:" row wrap; the Switch no longer shrinks in a crowded app bar. App-bar titles still truncate at 200 %.

## Code-reviewed semantics

- Switch: `role=switch`, `aria-checked`, accessible name from label. Unit-tested.
- Tabs: `role=tablist/tab/tabpanel`, `aria-selected`, roving `tabindex`, arrows/Home/End. Unit-tested.
- Dialog and BottomSheet (native `<dialog>`): focus trapped by the browser; `useModalDialog` stores the opener and
  returns focus on close (and on unmount). Unit-tested.
- Menu: first item focused on open, arrows/Home/End, Esc and selection return focus to the trigger, Tab closes.
- Live regions: tracker payment/overall status changes (`useStatusAnnouncement`, polite, silent on first load),
  store handoffs (existing, UX-05), basket verified-quote total (BasketPanel).
